Setup & Configuration
🔥 Firebase Configuration
Replace the config in both HTML files with your Firebase project config. Get it from: Firebase Console → Project Settings → Your apps → Web app → SDK setup
const FB_CONFIG = {
  apiKey: "YOUR_API_KEY",
  authDomain: "YOUR_PROJECT.firebaseapp.com",
  projectId: "YOUR_PROJECT_ID",
  storageBucket: "YOUR_PROJECT.appspot.com",
  messagingSenderId: "YOUR_SENDER_ID",
  appId: "YOUR_APP_ID"
};
🌱 Initialize Menu (First Time)
Populate your Firestore database with the full GRISTO menu. Run this once when setting up — it will not overwrite existing items.
🖨️ Printer Setup
The system prints using the browser's built-in print dialog. For thermal printers (80mm receipt):

1. Go to your OS printer settings
2. Set paper size to 80mm × Auto (or "Receipt" size)
3. Disable headers/footers in browser print settings
4. Set margins to None
5. Test print from the customer app by placing an order
🔒 Firebase Security Rules
Set these rules in Firebase Console → Firestore Database → Rules:
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{document=**} {
      allow read: if true;
      allow write: if true; // Demo only
    }
  }
}
And for Storage rules:
rules_version = '2';
service firebase.storage {
  match /b/{bucket}/o {
    match /menu-images/{f=**} {
      allow read, write: if true;
    }
  }
}
