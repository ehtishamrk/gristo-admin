🖨️ Printer Setup
The system prints using the browser's built-in print dialog. For thermal printers (80mm receipt):

1. Set paper size to 80mm × Auto (or "Receipt")
2. Disable headers/footers in browser print settings
3. Set margins to None
4. Test print from the customer app
